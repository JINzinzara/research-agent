# research-agent

## Purpose

1. 누구의 어떤 문제를 해결하는가? 
> 크립토 시장에 대한 흩뿌려진 정보를 종합하고 종합한 데이터를 바탕으로 과련 질문에 대해 답변을 한다. 직접 여러 데이터를 리서치하고 종합해야하는 시간 비용 및 인력 자원 낭비를 해결한다.
2. 어떤 데이터를 이용하는가?
> 경제/세계 뉴스, X와 같은 sns, Coingeco와 같은 크립토 관련 정보 사이트
3. 어떤 결과를 제공하며 무엇은 하지 않는가?
> 크립토 관련 현재 상황등의 정보를 제공하며, 트레이딩 종목 추천이나 자동 거래를 제공하지는 않는다.
